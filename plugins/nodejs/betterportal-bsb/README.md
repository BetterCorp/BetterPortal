# BetterPortal BSB Integration

Thin Node.js integration package that connects BetterPortal core contracts to BSB observability and runtime primitives.

Control-plane URLs must use HTTPS. HTTP is allowed only for `localhost`, `127.0.0.1`, or `[::1]`; userinfo, query strings, and fragments are rejected. Credential-bearing control-plane requests do not follow redirects, so configure the final URL directly.
