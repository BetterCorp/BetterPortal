# BetterPortal 11.0.13

## Breadcrumb navigation

Bootstrap1 and Bootstrap2 now use clickable breadcrumbs for ancestor navigation and the browser Back/Forward controls for history. The navbar no longer contains Back or Up buttons.

Every supplied parent path that resolves to an enabled GET page mount is clickable, including trails with more than two levels. Links preserve query strings and fragments. Literal text parents and the current page remain plain text; the current page carries `aria-current="page"`. Unresolved, ambiguous and protocol-relative parent paths remain excluded.

Theme authors should provide `[data-bp-current-title]` and `[data-bp-current-breadcrumb]`, remove `[data-bp-back]` and `[data-bp-up]` controls, and avoid replacement Back/Up rows in service views. The shared runtime no longer binds those button hooks. Parent paths remain service-relative and ordered from outermost ancestor to immediate parent. See [theme building](../building/themes.md#breadcrumb-navigation) and [routes and views](../building/routes-and-views.md).

Browser regression coverage clicks each of three ancestor levels and checks the resulting tenant URL and service request, query/fragment preservation, current-page semantics and history restoration. Both bundled themes are checked for the absence of Back/Up controls.

- Shell routing prevents redirect loops and keeps partial-request errors in their initiating content region ([#159](https://github.com/BetterCorp/BetterPortal/pull/159)).
- Default authentication improves verification and user management ([#160](https://github.com/BetterCorp/BetterPortal/pull/160)).
- .NET health diagnostics are available in the framework ([#142](https://github.com/BetterCorp/BetterPortal/pull/142)).
- Easy1 deployment waits for release tarball availability ([#157](https://github.com/BetterCorp/BetterPortal/pull/157)); release workflow OIDC permissions are scoped ([#158](https://github.com/BetterCorp/BetterPortal/pull/158)).
- Dependency updates include HTMX 4.0.1, otplib 13.6.0, WorkOS 12.2.0 and related maintenance updates.
