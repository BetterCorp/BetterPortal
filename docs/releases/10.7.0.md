# BetterPortal 10.7.0

The routing/PVE fixes, management authentication changes, and dependency updates are included in this release.

## Breaking routing contract

API handlers and renderers share `ctx.routeUrl(input?)`, returning an object or null with exactly `apiPath`, `viewPath`, `uiPath`, `absoluteApiPath`, `absoluteViewPath`, and `absoluteUiPath`. Omit the target to resolve self; explicit targets default to GET. Paths/view IDs, methods, parameters, queries, dependency aliases and mount selection are supported. Python and .NET definitions follow the same contract; their packages remain unpublished prototypes. Python/PyPI publishing and PR #105 are explicitly deferred.

APIs return domain data, state and cursors. Views resolve navigation and method-specific actions locally. Removed helpers, positional calls, legacy renderer URL fields and internal destinations forwarded in API responses fail the build. Documentation, theme guides and examples are migrated. See [route authoring and migration](https://github.com/BetterCorp/BetterPortal/blob/v10.7.0/docs/building/routes-and-views.md).

## Fixes

- PVE synchronization checks mounted paths and repairs changed mounts. Service path prefixes survive raw-anchor navigation and history replay, including installations under `/_bp/service/<id>`.
- Self/path resolution preserves repeated query values across SDKs. Renderer selectors affect only view destinations, and current UI helpers resolve the method they emit.
- Authress login fragments preserve their resolved token POST and provider callback destinations even when the address bar points to another page.
- WorkOS SDK 11 and setup-go 7 updates are included.
- Raw management routes verify app-scoped JWTs and matching grants. Management browser requests use the authenticated fetch helper; external installation endpoints receive no administrator bearer token. Reconfiguration/replacement requires update permission.
- Service/public-app URL bases reject unsafe schemes, credentials, query strings and fragments. Public app hosts must be origins without a path.
- Registry traversal/security fixes and compatible Node, Python and .NET dependency updates are included. BSB dependencies and deployment plugins use 9.7.4; AnyVali uses 1.1.6 throughout npm, Python and .NET. The npm audit reports zero findings.

## Upgrade

Upgrade custom services and views together, regenerate their route definitions, and fix authoring/type errors before deploying. Retain the fatal `bp run check-routes` prebuild check. Select `uiPath` for mounted navigation, `absoluteViewPath` for HTML/HTMX and `absoluteApiPath` for JSON actions; specify each action method in its renderer. Use `absoluteUiPath` for a public link consumed by an API, such as email or a callback.

The Coolify example uses `@betterportal/...@10.7` selectors. Rebuild/redeploy previews after updating so they obtain the new manifests and synchronization behavior.

Validation includes workspace build/tests, lint, signed commits, cross-language routing and HTTP interoperability CI. npm packages and BSB schemas publish through the tag workflow. Separate BP contract publication remains intentionally deferred.
